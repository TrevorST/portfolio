01

Marathon

BUNGIE / 2026

Bungie calls it "graphic retro futurism": retro roots, oddball cool, modern tech. Art director Joseph Cross frames it as Graphic Realism, where simplified, strong graphic design sits on top of believable scale and function. It is a sci‑fi world art‑directed like a poster.

  • M.01
    Graphic design as the world

    Built on The Designers Republic (the Wipeout studio), Ghost in the Shell, Aeon Flux, MGS2, F1 and MotoGP livery. Logos, stripes and type are part of the environment, not a layer on top.

  • M.02
    Everything is labeled

    Objects announce their function: "SEAL" on an airlock, "ATTACH" on tape, hazard stripes, coordinates like "TAU CETI IV // SURFACE DATA". Utility becomes pop art.

  • M.03
    Saturation turned to 11

    Near-black and off-white carry most of the frame, then one hyper-saturated acid colour hits hard. It is loud because the rest is quiet.

  • M.04
    Type with extreme widths

    Ultra-wide heavy caps against tiny monospaced captions. The jump in scale (huge to minuscule, nothing in between) is most of the drama.

  • M.05
    Digital texture

    Dithering, lattice patterns from 3D printing, scanlines, glitchy UI, datamosh flashes. The screen admits it is a screen.

WEB TRANSLATION

How we recreate it

Variable fonts with a wide axis for headings, a mono for every label. CSS grid lines on the page ground. Registration corners on panels. A canvas dither layer in the hero. One accent colour, never two at once.

WHAT NOT TO COPY

Don't cosplay the game

No fake weapons, no faction logos, no lore. We borrow the system (labels, contrast, rhythm) and apply it to real engineering content: repos, stacks, build numbers, commit hashes.

02

TypeSafe

TS.AI.0S1 / JEV

TypeSafe AI (makers of Jev, a model that returns typed decisions instead of text) takes the same sci‑fi energy and makes it austere. Where Marathon shouts, TypeSafe whispers in a lab coat.

  • T.01
    Versioned everything

    Components carry build tags like "Clock Tool 1.1", "Glider 1.1", "Version 0.01". The site reads like shipped software, not marketing.

  • T.02
    Glyphs as dividers

    Math and logic symbols (∵ ⩆) separate sections instead of lines or icons. Cheap, strange and memorable.

  • T.03
    Numbers are the hero

    "193.6x Faster, 444.6x Cheaper", "$0.000081 vs $0.013880", "0.114s". Precise figures with too many decimals feel honest and technical.

  • T.04
    Living algorithms

    Conway's Game of Life and small generative visuals run on the page. The decoration is itself computation.

  • T.05
    Contrarian, short copy

    "We took the opposite research direction." "Decisions, not strings." One idea per line, no filler.

  • T.06
    Framed headlines

    Big stat headlines sit inside four thin corner brackets, with a tiny mono footnote and an underlined "(Proof)" link under them. Flooded in a flat colour with dark type, tracked very tight. Rebuilt as the Frame Header in the kit.

WEB TRANSLATION

How we recreate it

Every project gets a build tag (MOODBOX 2.3). Stats read as raw metrics with real units. The hero background on this page is a running Game of Life, dithered in the signal colour.

War Dogs

  • W.01
    The // NAME // label

    Double slashes bracket the label like a code comment. Two small down-triangles sit at each end and point at the content below. This is our signature component: every section, card and nav item uses it.

  • W.02
    Label over plate

    A thin, dim label strip sits on top of a solid name plate. Small caps mono above, bold readable sans below. Hierarchy with almost no styling.

  • W.03
    Progress as a ring

    A heavy grey track with a thin glowing arc. We reuse it for loading states, skill meters and a page-scroll indicator.

  • W.04
    Glow from below

    A soft green bloom rises from the bottom of a pure black frame. It gives depth without gradients across the whole page.

04

Principles

7 RULES
P.01

One signal

Acid green is the only loud colour. It marks what matters: the current section, the primary action, live data. If two things are green, one of them is wrong. Magenta appears only in glitches and errors.

P.02

Label everything

Every block gets a // TAG //, a code (P.02, M.01) and ideally a real data point: a build number, a date, a commit hash, a stack. Labels carry true information, never lorem.

P.03

Scale is drama

Huge ultra-wide headlines, tiny mono captions, readable body text, and nothing in between. Skip the mid-size "nice" headings that every template uses.

P.04

Show the machine

Grid lines, registration corners, scanlines, dither and a running algorithm. The page looks like an instrument that is switched on, not a brochure.

P.05

Quiet ground

90% of any screen is void black, carbon panels and bone text. Texture stays subtle (low-opacity grid, faint scanlines) so the signal colour and the type can hit hard.

P.06

Motion is a boot, not a show

One orchestrated moment: a boot sequence on load, text that decodes from scrambled glyphs, rings that fill. Hover states snap (steps, not easing). Everything settles and stays readable, and respects reduced motion.

P.07

Terse, confident copy

Short declarative lines in the TypeSafe voice. Real numbers with units. "Shipped 14 builds. 0 regressions." beats a paragraph about passion.

DO
  • Use square corners and clipped (chamfered) corners on buttons
  • Put the // TAG // above every section heading
  • Give each project a build tag, status and stack chips
  • Keep text contrast high: bone on void
DON'T
  • Rounded cards with soft drop shadows
  • Purple-blue gradients or rainbow neon
  • Glitch effects on body text or anything you have to read
  • Fake game lore, weapons or faction logos
