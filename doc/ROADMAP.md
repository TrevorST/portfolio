# Roadmap

Each version is a release cut by release-please from Conventional Commits. See the [changelog](../CHANGELOG.md) for what shipped.

| Version | Scope | Status |
| --- | --- | --- |
| **0.1.0** | Foundation: Astro, Signal design system, projects and posts in Markdown, flat terminal with a modular command registry, CI/CD, Vercel. Resume content and `/about`. | Shipped 2026-09-29 |
| **0.2.0** | Privacy-first analytics (Umami, cookieless): visits, duration, referrers, and typed events for terminal commands, easter eggs, project links, resume views and contact clicks. Terminal input queueing fix. | Shipped 2026-09-29 |
| **0.3.0** | **3D terminal hero**: TRV-01, a retro computer you scroll into. The screen powers on and runs the same terminal engine, and you can type on it on desktop and on phones. A modelled `.glb` drops in without code changes ([doc/3D-MODEL.md](3D-MODEL.md)). | In review |
| **0.4.0** | CircleFlow live at `/play/circleflow`; MoodBox showcase of generated demos. | Planned |
| **0.5.0** | Polish, first real blog posts, easter eggs. | Planned |
| **1.0.0** | Custom domain and public launch. | Planned |
