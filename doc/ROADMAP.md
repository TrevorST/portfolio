# Roadmap

Each version is a release cut by release-please from Conventional Commits. See the [changelog](../CHANGELOG.md) for what shipped.

| Version | Scope | Status |
| --- | --- | --- |
| **0.1.0** | Foundation: Astro, Signal design system, projects and posts in Markdown, flat terminal with a modular command registry, CI/CD, Vercel. Resume content and `/about`. | Shipped 2026-09-29 |
| **0.2.0** | **3D terminal hero**: a retro computer you scroll into; the screen powers on and runs the same terminal engine. **Privacy-first analytics** (Umami, cookieless): visits, duration, referrers, and events for terminal commands, easter eggs, project links, resume views and contact clicks. | In progress |
| **0.3.0** | CircleFlow live at `/play/circleflow`; MoodBox showcase of generated demos. | Planned |
| **0.4.0** | Polish, first real blog posts, easter eggs. | Planned |
| **1.0.0** | Custom domain and public launch. | Planned |
